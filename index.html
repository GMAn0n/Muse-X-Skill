X Skill for Muse

The X Skill for Muse is a free, MIT-licensed command-line tool that operates an X (Twitter) account through the official X API v2. Post to X from Muse, read your timeline and mentions, search recent posts, and manage engagement — all from chat. Setup takes three steps and about five minutes: create an X developer app, install the skill, and run a one-time OAuth login with automatically refreshing tokens. Text posts cost $0.015; posts containing URLs cost $0.20.

Connect in 3 steps

About five minutes, once. After that, the skill runs your X account from Muse indefinitely.

Create an X developer app

At console.x.com:

  • Create a Project, then an App inside it
  • User authentication settings → enable OAuth 2.0, type Web App
  • Callback URI: http://localhost:3000/callback
  • Permissions: Read and write (add DM scopes for direct messages)
  • Copy the OAuth 2.0 Client ID and Secret from Keys and tokens
  • Add $10–20 prepaid credits under Billing

Install the skill

cp -r x ~/workspace/skills/

Log in once

python3 ~/workspace/skills/x/bin/x.py auth login --client-id <your-client-id>

Approve the app in your browser, paste back the code, and enter your client secret. Done — tokens refresh automatically, forever. Verify with:

python3 ~/workspace/skills/x/bin/x.py me

Frequently asked questions

Everything you need to know about the X Skill for Muse.

How do I connect my X account?

Three steps, about five minutes: create an X developer app at console.x.com with OAuth 2.0 and the callback http://localhost:3000/callback, install the skill with cp -r x ~/workspace/skills/, then run auth login --client-id and approve in your browser. See the Connect section above for the full walkthrough.

How much does the X API cost?

X bills pay-per-use: $0.015 per text post, $0.20 per post containing a URL, $0.005 per post read. A few posts a day is roughly $1–2/month. The --dry-run flag shows the exact cost before anything is spent.

Do I need to log in every time?

No — you log in exactly once. Tokens are stored locally with restricted file permissions and refresh automatically, so the skill keeps working indefinitely.

Is there a safe test mode?

Yes. Every command accepts --sandbox, which routes it to a local mock of the X API. No login, no spend, nothing published — exercise the full command set safely.

What can the skill do?

Publish posts (replies, quotes, dry-run previews), read your home timeline and mentions, search recent posts, look up users, manage likes, reposts, bookmarks, and follows, and read/send DMs — all through the official X API v2.

Is the X Skill for Muse free?

Yes — the skill is free and MIT-licensed. You only pay X's own pay-per-use API fees, about $1–2/month for typical use.
